# 食材圖片繪圖描述（Food Image Prompts）

共 56 張（目錄 55 種＋其他 other）。畫好後存成表中的檔名放進 `img/food/`，App 會自動換掉 emoji。

## 使用方式
1. **整套固定同一段風格**（下方「共用風格」），每張只換「主體」，整套才會一致。
2. 每張完整描述已組好，直接複製下方各區塊貼進繪圖 AI 即可。
3. 輸出 512×512 以上的正方形、**透明背景 PNG**；工具不支援透明背景時，先用白底再去背。
4. 先畫 3～5 張試風格，滿意後再批次畫完。

## 共用風格（Style）
```
flat vector illustration, soft pastel colors, clean simple shapes, subtle soft shadow, single subject centered, transparent background, no text, no logo, 1:1 square
```

## 排除（Negative prompt，工具有支援才填）
```
text, watermark, logo, hands, people, plate pattern background, realistic photo, busy background, multiple scenes
```
